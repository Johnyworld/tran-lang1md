▼적용 방법

웹브라우저 — 설치 없이

  1. Rom Patcher JS 를 엽니다.
  2. ROM file 에 원본 롬, Patch file 에 langrisser-ko.bps 를 넣습니다.
  3. Apply patch 를 누르면 패치된 롬이 내려옵니다.

브라우저 안에서만 처리되며 파일이 서버로 올라가지 않습니다.

macOS · Windows · CLI

  1. macOS — MultiPatch (BPS/IPS 지원 GUI)
  2. Windows — Flips 의 Apply patch
  3. CLI — flips --apply langrisser-ko.bps <원본롬> <출력롬>
BPS 를 권하는 이유는 원본 롬의 체크섬을 패치가 직접 검사하기 때문입니다. 롬이 다르면 패처가 거부하므로, 조용히 깨진 롬이 만들어지지 않습니다. IPS 에는 그 검사가 없으니 아래 해시를 먼저 확인하세요.

▼알아 둘 것

  • 패치 전에 만든 세이브 스테이트는 쓰지 마세요. 스테이트가 그래픽 메모리를 그대로 들고 있어서 글자가 깨져 보입니다. 리셋하고 새로 시작하거나 게임 내 저장에서 이어가세요. 배터리 세이브(.srm)는 원본과 호환됩니다.
  • 실기(플래시 카트)에서도 동작합니다. 매퍼를 쓰지 않고 헤더 체크섬을 정상값으로 다시 계산해 넣었습니다.
  • 스테이지 4 를 지원군(5턴) 등장 전에 끝내면 일부 대사의 이름·초상이 다른 인물로 나옵니다. 화자를 "참가자 목록의 뒤에서 N번째" 로 지정하는 원본 방식 때문이며 패치가 만든 문제가 아닙니다.
  • 전투 메뉴의 저장 은 원문 中断(중단 세이브)입니다. 실제 동작이 저장이라 그렇게 옮겼습니다.

▼만든 것에 대하여

폰트 구조와 텍스트 인코딩을 역해석하고, 한글 글리프를 문자열이 직접 들고 다니게 만들어 타일 한계를 넘겼습니다. 분석 기록·도구·번역 원고는 모두 공개되어 있습니다.

저장소 · 분석 기록 · 문제 신고

한글 폰트 — 번역과 이 페이지 모두 같은 폰트를 씁니다. 본문은 Galmuri11 (OFL-1.1 · 라이선스), 제목과 게임 내 메뉴·라벨 그래픽은 둥근모꼴(DungGeunMo, Public Domain)입니다.
게임의 저작권은 원저작권자에게 있습니다. 이 패치는 번역 데이터와 그것을 적용하는 차분만을 담고 있으며 게임 데이터를 배포하지 않습니다. 원저작권자·발행사와 아무 관계가 없는 비공식 팬 번역입니다.
